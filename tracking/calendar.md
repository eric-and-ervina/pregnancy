## 🗺️ How to Use This Tracker

1. **Look up any date** in the calendar table below
2. Read the **Week #** column to see how many weeks pregnant she is
3. The **Gestational Age** column shows the exact weeks + days at the end of that week
4. The **Days Since LMP** column helps with quick date-to-days conversion

### Quick Lookup Formula

If you know the number of days since LMP (25 Jan 2026):

```
Weeks = Days ÷ 7          (integer division)
Days  = Days % 7          (remainder)
```

## 📐 How the Calculation Works

Pregnancy is calculated from the **first day of the Last Menstrual Period (LMP)**, not from conception. This is the standard medical convention used by all OB/GYNs.

- **Formula:** Gestational Age = Today − LMP
- **EDD:** LMP + 280 days (40 weeks)
- **Conception (ovulation):** Approximately LMP + 14 days

> **Why use LMP instead of conception?** Because the LMP date is usually known with certainty, while the exact conception date is often unknown. All pregnancy milestones (scans, tests, due dates) are calibrated to LMP-based dating.
